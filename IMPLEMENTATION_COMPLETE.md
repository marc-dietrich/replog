## 📋 Überblick

Ein **vollständig implementiertes, produktionsreifes Backend** für die Gym-Tracking-Anwendung mit:

- ✅ **FastAPI** REST API mit OpenAPI/Swagger
- ✅ **PostgreSQL** mit SQLAlchemy 2.x ORM
- ✅ **JWT Authentication** mit Bearer Tokens
- ✅ **Repository & Service Pattern** Architektur
- ✅ **Async/Await** für Performance
- ✅ **Docker & Docker Compose** für Deployment
- ✅ **Alembic** für Database Migrations
- ✅ **Pytest** Integration Tests
- ✅ **Type Hints** (Python 3.13)
- ✅ **CORS** Support

```bash
# Migrationen ausführen
```

## 📊 Datenmodelle

### User
```python
- id: UUID (PK)
- email: str (nullable, unique)
- display_name: str (nullable)
- status: UNCLAIMED | ACTIVE
- created_at, updated_at: datetime
```

### ExerciseGroup
```python
- id: UUID (PK)
- user_id: UUID (FK → User)
- name: str
- sort_order: int
- created_at, updated_at: datetime
```

### Exercise
```python
- id: UUID (PK)
- user_id: UUID (FK → User)
- group_id: UUID | None (FK → ExerciseGroup)
- name: str
- sort_order: int
- legacy_id: str | None
- created_at, updated_at: datetime
```

### Entry
```python
- id: UUID (PK)
- exercise_id: UUID (FK → Exercise)
- date: date
- weight: DECIMAL(6,2)
- reps: integer
- note: str | None
- created_at, updated_at: datetime
```

### Migration
```python
- id: UUID (PK)
- migration_token: str (unique)
- payload: JSONB
- claimed: bool
- user_id: UUID | None (FK → User)
- created_at, updated_at: datetime
```

## 🔐 API Endpoints (Kurzbersicht)

### Auth
```
POST   /api/auth/guest        # Guest User erstellen
GET    /api/auth/me           # Aktuelle User Info
```

### Groups
```
GET    /api/groups            # Alle Gruppen auflisten
POST   /api/groups            # Neue Gruppe erstellen
PATCH  /api/groups/{id}       # Gruppe aktualisieren
DELETE /api/groups/{id}       # Gruppe löschen
```

### Exercises
```
GET    /api/exercises         # Alle Übungen auflisten
POST   /api/exercises         # Neue Übung erstellen
PATCH  /api/exercises/{id}    # Übung aktualisieren
DELETE /api/exercises/{id}    # Übung löschen
GET    /api/exercises/{id}/entries  # Einträge einer Übung
```

### Entries
```
POST   /api/entries           # Neuer Eintrag erstellen
PATCH  /api/entries/{id}      # Eintrag aktualisieren
DELETE /api/entries/{id}      # Eintrag löschen
```

### Migrations
```
POST   /api/migrations        # Migration vom Alt-System initiieren
POST   /api/migrations/claim  # Migration übernehmen & User erstellen
```
